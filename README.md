# Kahve Falı AI Yorumcusu

## Dünyanın En Ciddi, En Abartılı ve En Gereksiz Kahve Fali Yorumlama Aracı

Bu proje, insanlığın en büyük sorularından birine cevap arar: **"Kahve fincanım bana ne diyor?"**

Cevap: Genellikle hiçbir şey. Ama biz yine de yorumlarız.

### Nasıl Çalışır?

1. Python 3 kurulu olsun.
2. `python kahve_fali.py` yaz.
3. Fincanı çevirmesini izle.
4. Yorumu oku.
5. Varoluşsal kriz geçir.
6. Tekrar çalıştır.

### Özellikler

- **Rastgele Yorumlar**: Her seferinde farklı (ama aynı derecede anlamsız) yorumlar.
- **Dramatik Bekleme**: Fincan çevirme animasyonu ile gerilim yaratır.
- **Bilimsel Olmayan Ama Hissettiren**: Tamamen uydurma, ama derin görünen cümleler.
- **Kriz Seviyesi**: Maksimum. Kullanıcı sorumluluğu kendine aittir.

### Neden Bu Proje?

Çünkü dünya zaten yeterince ciddi. Birinin de kahve falından varoluşsal kriz üretmesi lazımdı.

Bu kod, aslında bir metafor. Kahve bittiğinde ne kaldığını sorgulatır. Belki de hiçbir şey.

### Kurulum

```bash
git clone https://github.com/Tentivory/kahve-fali-ai-yorumcusu.git
cd kahve-fali-ai-yorumcusu
python kahve_fali.py
```
